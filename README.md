# HTML to MP4 Video Studio 🎬

[![Node.js](https://img.shields.io/badge/Node.js-22.x-green.svg)](https://nodejs.org/)
[![Docker](https://img.shields.io/badge/Docker-Ready-blue.svg)](Dockerfile)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Universal MP4](https://img.shields.io/badge/Codec-H.264%2FAAC-purple.svg)]()

Convert HTML artifacts, Canvas 2D/WebGL animations, and CSS visuals generated by **Claude** or any AI into high-quality **MP4 video files**.

---

## 🌟 Key Features

- **Upload & Code Support**:
  - Drag & drop `.html`, `.htm`, or `.zip` archives (with bundled images, CSS, and JS).
  - Paste raw HTML/CSS/JavaScript code directly with instant live preview.
  - Preloaded Claude demo animations (*Cyberpunk HUD Reel* & *Nebula Particle Flow*).
- **Flexible Aspect Ratios & Resolutions**:
  - 📱 **Vertical (9:16)**: 1080×1920 (Instagram Reels, TikTok, YouTube Shorts), 720×1280, 1440×2560.
  - 🖥️ **Horizontal (16:9)**: 1920×1080 (Full HD YouTube/Desktop), 1280×720, 3840×2160 (4K Ultra HD).
  - ⏹️ **Square (1:1)**: 1080×1080 (Instagram Feed).
  - ⚙️ **Customize Size**: Custom Width and Height in pixels with instant aspect ratio calculation and a **⇄ Swap Dimensions** button.
- **High-Quality Output**:
  - **30 FPS & 60 FPS** ultra-smooth rendering.
  - Quality presets: Ultra High (CRF 16 Lossless), High (CRF 20), Balanced (CRF 24).
  - Configurable recording duration (1s to 180s).
  - Configurable startup delay (0.5s–3.0s) so fonts, scripts, and canvas initialize smoothly.
  - Universal H.264 (`yuv420p`, `+faststart`) with a universal AAC audio track, 100% compatible with iOS, Android, Premiere Pro, DaVinci Resolve, CapCut, Instagram, TikTok, and YouTube.
- **Interactive Studio UI**:
  - Real-time responsive mockup frame that resizes dynamically to the target aspect ratio.
  - Progress bar with live frame counter during rendering.
  - In-browser MP4 video player and one-click download.

## 🚀 Quick Start (Local)

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or newer)
- Google Chrome or Microsoft Edge installed on your system

### 1. Installation
```bash
git clone https://github.com/<your-username>/html-to-mp4-video-studio.git
cd html-to-mp4-video-studio
npm install
```

### 2. Run the Studio
```bash
npm start
```
Or on Windows, simply double-click `start.bat`.

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🐳 Deployment with Docker

The repository includes a production-ready `Dockerfile` with Chromium and FFmpeg pre-configured.

### Run with Docker Compose
```bash
docker-compose up -d
```
Visit `http://localhost:3000`.

### Deploy to Cloud (Railway, Render, Fly.io)
- **Railway / Render**: Connect your GitHub repository and select **Docker** as the environment. It will automatically build and deploy using the included `Dockerfile`.
- **Fly.io**:
  ```bash
  fly launch
  fly deploy
  ```

If you haven't created your GitHub repository yet, follow these 3 steps:

1. **Create a new repository** on [GitHub](https://github.com/new) (e.g. named `html-to-mp4-video-studio`). Leave "Initialize this repository with a README" unchecked.
2. In your terminal, link your remote repository:
   ```bash
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   ```
3. Push your code to GitHub:
   ```bash
   git branch -M main
   git push -u origin main
   ```
